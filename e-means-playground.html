The e-means playground

Compare e-means with Lloyd k-means on 2D synthetic distributions

Data
Parameters
epochs: 0.00
Lloyd (full batch)
e-means (scaling-law batch + step)
Loss (MSE): train vs held-out test
e-means train e-means test Lloyd train Lloyd test

Note: e-means runs here with dead-cluster revival switched off, because on very low-dimensional data such as these 2-D sets revival degrades its results. Lloyd still re-seeds empty clusters as usual. Initialization is done with random sampling from the dataset. The batch size used is B/8, where B is the batch given by the default scaling law.
